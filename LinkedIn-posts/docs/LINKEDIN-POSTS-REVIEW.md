## Formatting Checklist for All Posts

### ✅ Required Formatting Elements:
1. **Section Headings:** Unicode bold (𝐖𝐡𝐚𝐭, 𝐓𝐡𝐞, etc.) with two trailing spaces after colon/question mark
2. **Bullet Points:** ▶ character with two trailing spaces after each line
3. **File Names:** Zero-width space (​) in file names to prevent LinkedIn auto-linking (e.g., `script​.sh`)
4. **URLs:** Clean URLs (no zero-width spaces) so they remain clickable
5. **Date Heading:** Format `## [Month Day, Year](LinkedIn-URL)` with `[LinkedIn](LinkedIn-URL)` link below
6. **Code Blocks:** Use plain text, not markdown code blocks (```bash) for LinkedIn

### ⚠️ Common Issues Found:
- Missing trailing spaces on section headings
- Missing trailing spaces on bullet points
- File names without zero-width spaces
- Code blocks using markdown syntax instead of plain text
- Placeholder LinkedIn URLs that need updating
